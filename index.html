BZ's Speakeasy — Complete Architecture, Mixology & Design System Reference (README.md)

A minimal, modern, Japanese wabi-sabi inspired cocktail web suite for BZ's Speakeasy consisting of a guest-facing mobile bar menu (index.html), a passcode-protected internal cocktail development and recipe book with live ingredient usage tracking (lab.html), the 52-item Bar Inventory & Perishables Mapping CSV (bar_inventory_list.csv), and this master specification document (README.md).

1. Core Mixology, Naming & Recipe Rules

  • 12 Curated Cocktails (6 House Signatures + 6 Classic Adaptations):
    • House Signatures (6): Komorebi Highball, Silk & Saffron, Evening in Miyazaki, Velvet Nocturne, Rosewater Canopy, Amalfi Gold Drop.
    • Classic Adaptations (6): Rosepetal Clover Club (Clover Club), Yuzu Blossom Hemingway (Hemingway Daiquiri), Alpine Orchard Gimlet (Gin Gimlet), Golden Hour Spritz (Hugo & Venetian Spritz), Sunlit White Negroni (White Negroni), Twilight Indigo Martini (Classic Dry Martini).
  • Naming Conventions (Max 3 Words & Zero "Silk" Overuse):
    • Every cocktail name is strictly limited to 3 words or fewer so guests can order effortlessly.
    • The word "Silk" is restricted to appear at most once across the entire 12-cocktail menu (used exclusively in Silk & Saffron). Former working titles were renamed to Amalfi Gold Drop, Rosepetal Clover Club, and Twilight Indigo Martini.
    • Every cocktail in lab.html includes a dedicated inspirationStory field explaining the creative inspiration, sensory goal, and naming rationale.
  • Strict Single Primary Base Spirit Rule (No Base Spirit Blending): Every cocktail uses one single primary base spirit (never mixing two gins, two rums, two bourbons, or two vodkas in the same recipe) so each bottle's provenance and character shine clearly.
  • Simplified Complexity (≤6 Total Ingredients): Every recipe contains 5 or 6 total ingredients (including base spirit, modifiers, citrus juices, syrups, bitters, and garnishes) for fast, repeatable service. Unused bottles remain cleanly tracked as reserve stock in INVENTORY.
  • Foundational Flavor Balance Rule: Every recipe harmonizes sweet, sour, bitter, and alcohol elements so no single component overwhelms the palate, while strictly excluding culinary saltiness, umami, or savory vegetal notes.
  • Spirit Diversity Cap: No alcoholic bottle or bitter appears in more than 3 cocktails across the entire 12-drink menu.

3. UI/UX Design System, Security & Technical Architecture

  • Japanese Wabi-Sabi Spatial Calm (100% English Text):
    • Expresses Japanese calm through generous whitespace (ma), hairline dividers, and warm natural tones—using zero Japanese characters (no kanji, hiragana, or katakana anywhere in UI, data, or comments).
    • Brand Emblem: Custom inline SVG BZ monogram and geometric cocktail coupe crest in the sticky header and guest menu card.
    • Light Mode (Daytime 6:00 AM – 5:59 PM Default): Washi Cream background #F7F3EC, Elevated card #FBF9F5, Subtle fill #EFEAE1, Charcoal ink #2B2B2B, Slate Indigo accent #334756, Moss Green #5B6E58, Terracotta Clay #9E5A47, Vermilion Seal #B83B2B.
    • Dark Mode (Nighttime 6:00 PM – 5:59 AM Default): Sumi Charcoal background #1B1A18, Elevated card #24221F, Warm cream ink #EDE8DF, Indigo accent #86A8C0.
    • Theme Switcher: Automatic time-based initialization via new Date().getHours() paired with a 44x44px circular icon-only Sun/Moon toggle in the header for manual override.
    • Typography: Headings in "Cormorant Garamond", Georgia, serif; Body & UI in "DM Sans", -apple-system, sans-serif (16px minimum body text); Numeric specs & prompts in "JetBrains Mono", monospace.
  • Guest Bar Menu (index.html) Rules:
    • Shows ONLY: (1) Cocktail name (≤3 words), (2) Minimal circular icon-only SVG glass badge (no text label), (3) Simplified guest-friendly ingredient names mapped from bar_inventory_list.csv (no measurements), and (4) A single-line italic flavor profile.
  • Stealth Staff Passcode Protection (lab.html & README.md):
    • Internal navigation links (Lab and Docs) are styled as discreet, low-contrast text links in the header.
    • Clicking Lab or Docs while locked opens an in-page modal checking the hardcoded passcode benzzers.
    • Stealth UI Rule: Never display or hint at the passcode benzzers anywhere in the modal, UI text, or tooltips.
  • Sandboxed Preview & GitHub Pages Resilience:
    • Never use blocking browser dialogs (prompt(), alert(), confirm()).
    • Never include raw closing tags (</script>, </head>) inside inline JavaScript strings; construct exported HTML tags via string concatenation ('<' + '/script>').
    • Pre-populate the Guest Bar Menu HTML in the static markup and wrap DOM setup in try/catch so the page never renders a blank screen.

4. Data Schema (COCKTAILS & INVENTORY Objects)

Field Type Description
id / name string Unique kebab-case ID and cocktail title (strictly ≤3 words; "Silk" used at most once across the menu).
classification / classicInspiration string "Original Signature" or "Classic Adaptation", plus classic inspiration name.
baseSpiritCategory / glassType string Single primary base spirit category and verified glassware name.
drinkColor / garnish string Appetizing visual color profile and modern purposeful garnish specification.
mixingTechnique string Prominent primary technique label (Stirring, Shaking, Dry/Wet Shake, or Built) with ice & dilution specs.
inspirationStory string Dedicated storytelling narrative explaining the drink's inspiration, creation process, and naming rationale.
conceptStory / balanceExplanation string Technical bar concept and how sweet, sour, bitter, and spirit proof are balanced.
guestIngredients / labIngredients string[] 5–6 simplified guest-facing names (for index.html) and exact technical bottle names (for lab.html).
recipeSpec Array<{item, ml, oz, note}> 5–6 exact single-serving measurements in milliliters (ml) and US fluid ounces (oz).
